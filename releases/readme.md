# ARMv7l ML/OCR Asset

**A collection of pre-built, optimized libraries** for machine learning and EPUB document processing on ARMv7l architecture (Raspberry Pi, Orange Pi, etc.), compiled on the same MeLE A1000 system as the main PyTorch build.

## 🚀 Quick Installation

```bash
# Install PyTorch 2.5.0 (recommended) or 2.3.0
pip install torch-2.5.0+armv7l.lpt.mlh.2025.git32f585d-cp311-cp311-linux_armv7l.whl
# or
pip install torch-2.3.0+armv7l.lpt.mlh.2025-cp311-cp311-linux_armv7l.whl

# Install core scientific computing stack
pip install numpy-2.3.5-cp311-cp311-linux_armv7l.whl
pip install scipy-1.16.3-cp311-cp311-linux_armv7l.whl
pip install pandas-2.3.3-cp311-cp311-linux_armv7l.whl
pip install scikit_learn-1.5.2-cp311-cp311-linux_armv7l.whl

# Install computer vision packages
pip install opencv_python_armv7l-4.9.0-py3-none-linux_armv7l.whl
pip install pillow-12.0.0-cp311-cp311-linux_armv7l.whl
pip install torchvision-0.20.0a0+afc54f7-cp311-cp311-linux_armv7l.whl

# Install OCR packages
pip install tesseract_ocr_armv7l-5.3.0-cp311-cp311-linux_armv7l.whl
pip install pytesseract-0.3.14-py3-none-any.whl
pip install pix2tex-0.1.4-py3-none-any.whl

# Install NLP packages
pip install spacy-3.8.11-cp311-cp311-linux_armv7l.whl
pip install transformers-4.57.0-py3-none-any.whl
pip install sentencepiece-0.2.2-cp311-cp311-linux_armv7l.whl

# Install utility packages for document processing
pip install lxml-6.0.2-cp311-cp311-manylinux_2_31_armv7l.whl
pip install beautifulsoup4-4.14.3-py3-none-any.whl
pip install ebooklib-0.20-py3-none-any.whl
pip install html2text-2025.4.15-py3-none-any.whl

# Install build tools (if needed for compilation)
pip install cmake-4.2.0-py3-none-manylinux_2_31_armv7l.whl
pip install cython-3.2.2-cp39-abi3-manylinux2014_armv7l.manylinux_2_17_armv7l.manylinux_2_31_armv7l.whl
pip install ninja-1.13.0-py3-none-manylinux_2_28_armv7l.manylinux_2_31_armv7l.whl
